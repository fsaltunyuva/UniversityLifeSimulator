# University Life Simulator

Run through several minigames to keep your academic, basic, and social needs above 0 for 5 minutes. To play the game, use [this itch.io link](https://fsaltunyuva.itch.io/university-life-simulator).

Used assets are listed in the [UsedAssetReferences.md](UsedAssetReferences.md) file.
